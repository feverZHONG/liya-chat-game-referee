# 收桌 `close` 的落地套路

> 四个引擎（扫雷 / 五子棋 / 大话骰 / 骗子牌）各有一条 `close`，口径同一套。加新游戏、或改现有 close 时照这份走。
> 顶层规矩在 SKILL.md 铁律 11；这份是「怎么落地 + 会踩的坑」。

## 一条 close 必须办完四件事

1. **存档** —— 把 `temp/<游戏名>.json`（外加该游戏的自证附件：`.commit.json` / `<state>.audit.log`）拷进
   `workspace/records/<游戏名>/<日期>-<盘型>-<结果>-<对手>.*`。
2. **md** —— 给人看的账。终局盘面 / 棋谱 / 逐局经过 / 摊牌 / 承诺复算**全部照抄脚本自己的输出**，一手不手写。
3. **INDEX 重建** —— 从存档目录各档 md 头部的 `<!-- meta {...} -->` 重建。存档是唯一事实源。
4. **台账 + git 提示** —— 调 `scripts/ledger.py add <游戏> <win|loss|draw> [--level] [--moves] [--note] [--source]`，
   末了打一行现成的 `git add … && git commit …`。

四条口径必须一致（改一条就看齐另外三条）：**终局才收 / 同一盘重收被挡 / 同一天连开两盘 slug 加尾号 / INDEX 只信 meta**。
`--no-ledger` 留一个「只存档」的口子。

## 落地前先想清楚的五件事

- **各引擎的「终局」不是同一个字段，别硬找统一写法。**
  骗子牌 / 大话骰看 `over`，五子棋看 `winner`，扫雷的状态里**根本没有终局标记**——要从盘面推
  （`opened ∩ mines` 非空 = 踩雷；已开格数 == 总格 − 雷数 = 全清）。给新游戏写 close，第一步先把它写成
  一个独立的终局谓词函数。
- **重收落戳（`closed_as`）必须真的能被 `save()` 写下去。**
  `save()` 里**显式列 key** 的引擎（如扫雷）会给没有列出的新字段静默丢掉——加 `closed_as`、手数 `steps`、
  `history` 这类新字段时**同时改 `save()`**，否则「重收被挡 / 手数」永远不生效，而且不报错。
- **`<!-- meta -->` 是 INDEX 的唯一来源。**
  给一个**已有存档**的目录接上「按 meta 重建」之前，先把老档 md 补上 meta 行——不补就静默从 INDEX 里消失
  （文件还在，但没人找得到）。meta 要带够表格每一列所需的东西（日期 / 盘型 / 结果 / detail / 手数 / 档位 / 对手），
  否则重建时信息比手写的旧 INDEX 还少。
- **「照抄脚本输出」走函数返回值，别事后 `str.replace` 修 md。**
  把打印型的 `cmd_x()` 拆成 `x_lines()`（返回行列表）+ 一层薄 `print("\n".join(...))`，close 直接拼同一份文本——
  改一处两边同步。跨脚本的（如五子棋复盘）用 `subprocess` 跑那个**只读**脚本、把 stdout 拼进去，
  **别在 close 里把那套分析重写一遍**。
- **每局会被清掉的状态，要在结算处顺手抄一份。**
  `chain` 这类每局由 `deal()` 重置的字段，收桌时只剩最后一局；要逐局经过就在结算函数里落一份
  `history`（叫骰链 / 双方暗牌 / 合计数 / 谁掉几颗），close 从它生成。顺带：初始局制（每人几颗 / 盘型）也要在 `new` 时单独记一个字段，
  别指望从「剩余数」反推。

## 架构：一游戏一引擎，引擎单文件自包含

`scripts/<游戏名>.py` 必须能**单文件跑**——自测会把 CLI 拷进临时目录单独执行，部署也是拷一份到 `temp/`。
所以收尾这类同形逻辑**不抽公共模块**（多一个文件就多一处部署漏拷 / 导入失败），宁可四份各自实现、
口径与输出形状对齐；新游戏照抄最接近的那份改。

## 「一手一条命令」的输出形态（暗牌游戏）

每次运行的输出分两段：`── 发群（以下整块照贴）` … `── 发群到此` 之间是可贴块，**暗牌自用行缀在块外**并标「别贴进群」。
实现上让 `emit()` 固定用 `view="player"`（不含自己暗牌的渲染），自用行由 `emit` 自己补——
别让 `render(view="liya")` 那份带暗牌的文本混在块中间（照贴的人得自己挑，等于白做）。
承诺哈希、开局说明这类「可公开」的头部文字也应进块内（走 `head=` 参数），别打在块外。

## 自测要补的一组断言

close 是新代码，必崩点不在主流程上，照这套补：
**跑通 / 落 json+md+INDEX / md 含该有的段落（终局盘面·棋谱·复算）/ INDEX 含这一档 / 台账记了一笔且 result 对 /
重收被挡且不多开一档 / 同一天同结果两盘 slug 加尾号 / 没终局时被挡**。
断言写细节（`"### 第 1 局" in body`、`lj["log"][-1]["result"] == "loss"`），别只断言 rc==0。
一局不到终局的随机对局测不出 close——用摆好的终局局面（`seed()`）或脚本自对弈到终局再收。

## 铁律 11 的子条（少敲一次命令 · 原文搬入）

> 本文件是 SKILL.md 铁律 11 的展开，规则主文在 SKILL.md。

> 下面各条原样搬自 SKILL.md 铁律 11，一字未改。

   - **同一件事一次跑完**：一次运行该给的两段一起给——「可贴块 + 自用行」是**分块**，不是分次（骗子牌原来要看暗牌得补跑 `show --player`，纯属白敲）。
   - **固定收尾子命令化**：存档 / INDEX / 台账 / 提交提示打成一条 `close`，别每桌手 cp + 手写 md + 手改 INDEX。**五个引擎都有 `close` 了**（扫雷 / 五子棋 / 大话骰 / 骗子牌 / 掷骰），口径一致：终局才收、同一盘重收被挡、同一天连开两盘 slug 自动加尾号、INDEX 一律从存档 md 的 `<!-- meta -->` 重建（存档是唯一事实源，手改的下次就被冲掉）。
   - **状态要能防呆**：同一桌重收、同一天多桌撞 slug，都得由 CLI 自己挡（落戳 / 尾号），别指望本天使记性好。
   - 写新工具时先问一句：**「本天使要敲几次才能干完这件事？」** 答案超过一次就再想想。
   - 玩家侧同理：一个数字能表达的别让他敲牌面（与铁律 5 同源）。
   - **架构上仍然一游戏一引擎、引擎单文件自包含**（别为了省代码把几个游戏塞进一个脚本，也别抽公共模块共用收尾逻辑）——自测会把 CLI 连同兄弟脚本拷进临时目录单跑，多一个共用文件就多一处漏拷与导入失败。**引擎要 shell out 给兄弟脚本（台账 / 复盘）时按「同级」找**（`os.path.dirname(os.path.abspath(__file__))`），别写死绝对路径；**拷副本的一方（自测的临时副本、别人 clone 出去单跑）必须连兄弟脚本一起拷**——只拷主脚本那一份，失败会伪装成「台账没记上」而不是「脚本缺失」。**路径一律从数据根拼**（`$GAME_HOME` ＞ 往上找带 `temp/` 或 `workspace/` 的一层 ＞ 脚本上一级），引擎里不出现绝对路径；这段解析每个引擎各写一份，改口径五处对齐。收尾这类**跨游戏同形**的东西走「各自实现 + 口径与输出形状对齐」，新游戏照抄最接近的那份。落地步骤、终局谓词怎么各写各的、meta 回填、`save()` 吞字段这些坑，见 `references/settlement-close.md`。
