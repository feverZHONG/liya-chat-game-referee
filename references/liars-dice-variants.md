## A · 大话骰变体（opt-in）

开桌：`new --variant fanpi --variant minbid --variant quan`（或 `--variants fanpi,minbid,quan` / `--variants all`）。

| 变体 | 规则 | 依据 |
|------|------|------|
| **反劈** `fanpi` | 开 1 码 / 劈 2 码 / 反劈 4 码。**双向**：阁下劈本天使 → 本天使可反劈（AI 自动判）；本天使劈阁下 → 阁下用 `fanpi` 反劈或 `open` 认账 | 开1/劈2/反劈4（维基百科·大話骰、百度百科） |
| **起叫下限** `minbid` | 每局第一手（起叫）设下限：喊 1 至少＝存活人数；非斋至少＝⌈总骰数×0.3⌉；斋至少＝存活人数 | 起叫＝人数×1.5、斋≥人数（百度百科）；2 人常见共识 2/2/3（知乎·开平规则） |
| **围骰 / 全骰** `quan` | 计数：围骰（1＋单一点数）该点 +1、全骰（全同点）+2（房源版全同点只 +1，开了这个才升级）；惩罚：**被开者（叫骰方）判输时手里是围骰/全骰 → 惩罚翻倍** | 百度百科 3.0 / 4.0 版 |

**划掉（1v1 不成立）**：反弹（上家数量 +2 改叫骰顺序——顺序是多人局才有的东西）、跳杀 / 连杀 / 陪饮 / 筹码 / P 版（多人或喝酒场景）。
顺子算 0 / 双方顺子重摇一次、豹子 +1 已在默认版里，别再当新变体重捞。
**边界**：反劈不接无限翻倍（否则能无限抬杠），1v1 止于 4 码。

## C · 骗子牌（Liar's Deck）· 新游戏

`games/liars-deck/` + `scripts/liars-deck.py` + 自测。**1v1 版**（对齐合集的对擂向）。

- **牌组**：6Q + 6K + 6A + 2 王（万能）＝ 20 张；每人 5 张手牌。
- **一轮**：随机定目标牌 ∈ {Q,K,A}；轮流「出牌」——暗出 1–3 张，宣称全是目标牌（可真可假）。
- **回合选择**：下家要么质疑，要么自己接着出。质疑 → 翻牌：有假牌→出牌者吃枪；全真→质疑者吃枪。
- **一轮结束**：只结束于一次质疑。一方手牌出空只是**该方本轮跳过回合**；1v1 下只剩对方有牌 → 对方**必须**质疑最后一手，谁吃枪看那一手真假（所以出空方的最后一手必须是真的）。无「认了 / 弃权」选项。官方口径见 **E 节**。
- **左轮**：每人 6 仓 1 弹，每挨一枪转一格、转到弹格出局。**子弹位置 + 双方手牌开局承诺哈希**（本天使既坐庄又下桌，公平条款照做）。
- **渲染**：文字盘面为主 + `--png`（阁下视角：他的牌明、本天使的牌扣着）。

## E · 官方规则核对（2026-09-15）

> 源：debigare《How to Play Liar's Deck》（据游戏内教程 + 开发者评论，最权威）／TheGamer／Steam 中文指南「骗子酒馆快速入门」／Wikipedia。三源交叉，无冲突。

**官方 Liar's Deck 基础规则**

- 牌组 20（6K/6Q/6A/2 王）；每人 5 张（4 人刚好发完）；每轮洗 Table deck（1K/1Q/1A）翻顶定目标牌。王算真 → 每轮 8 真 / 12 假。
- 回合**只有两个选项**：暗出 1–3 张，或叫 LIAR（**本轮第一手不能叫**）。
- 手牌出空 → 该玩家本轮跳过回合；**只剩 1 人有牌 → 那个人必须叫 LIAR**。
- 叫 LIAR → 翻开被质疑者上一手：有 ≥1 张假 → 被质疑者转轮盘；全真 → 质疑者转轮盘。
- 轮盘：自己的左轮（1 实弹 + 5 空仓），**实弹位固定、逐格推进** → 1/6、1/5、1/4、1/3、1/2、1。中弹出局，左轮不重置。
- 一轮结束于一次质疑；下一轮先手 = 吃枪的人；整局终了 = 只剩 1 人。
- **1v1 推论**：出空即「只剩一人有牌」→ 对方**必须**质疑；所以最后一手必须是真的（中文攻略原话：「一对一时最后出的牌必须是Table牌，否则你会反胜为败给自己一枪」）。

**本天使实现的三处偏差**

| # | 偏差 | 现状 | 官方 |
|---|------|------|------|
| 1 | 🔴 `pass`（认了）是自创机制 | 本天使出空 → 阁下可 `open` 或 `pass`（pass = 阁下吃枪） | 回合只有「出牌 / 叫 LIAR」，**无弃权**；只剩一人有牌 → **必须**质疑 |
| 2 | 🟡 「出空者脱身」表述易读成「出空 = 稳赢」 | `games/liars-deck/rules.md`「该方本轮脱身」；本节上文「另一方…自动被质疑 → 吃枪」 | 出空只是**本轮跳过**；谁吃枪仍看最后一手真假。多人局里出空**不结束轮次**，1v1 因强制质疑才看起来像结束 |
| 3 | 🟡 文档称 AI 吃「公开出牌史」 | `games/liars-deck/rules.md` 第四节 / `SKILL.md` 都这么写，但 `ai_p_true` 只用自己手牌 | （文档与实现不符，非官方规则问题） |

偏差 1 的实际影响：`pass` 是**严格劣势选择**（理性方永远选质疑），不改变理性博弈结果，但属规则外、且把「出空」包装成逼对方认输的武器——与官方「最后一手经得起质疑」的核心张力相反。

**处置（2026-09-15 阁下批「一并理顺」）**：三处偏差全修 ✅——① 删 `pass` / `concede`，出空一律强制质疑（两方对称）；② `games/liars-deck/rules.md` 改写「出空」口径（跳过回合 ≠ 稳赢；1v1 下最后一手必须真）；③ `games/liars-deck/rules.md` / `SKILL.md` 的 AI 口径改成实话（只吃自己手牌）。自测补两条回归：出空＋最后一手真 → 质疑者吃枪；出空＋最后一手假 → 出空方吃枪。

**一致（做对了）**：牌组 / 手牌 / 目标牌三选一 / 混牌判假（≥1 张假即说谎）/ 王万能 / 出牌 1–3 张数量随意 / 轮盘固定弹位逐格 / 先手 = 吃枪者 / 双承诺哈希。

**仅多人版才需补**：本轮第一手不能叫 LIAR；30 秒限时。

**再加两层（2026-09-15 阁下批「甲」+「丙」）**

- **甲 · 蒙眼**：文字盘面双方手牌都只给张数，牌面只走牌桌图；本天使三不做（不 vision 读图 / 不 read 状态 json / 不翻含暗牌输出）；`<state>.audit.log` 自动记下本天使可见的一切供阁下审计（⚠️ 含本天使自己手牌明文，审计请等收桌；阁下的暗牌对局中只有张数）；默认出图（`--no-png` 关）。
  - 顺手堵的口子：出牌报错不再列阁下手中牌；局中 `reveal` 只摊本天使那半（原来能借它偷看阁下暗牌）。
  - **补丁（同日）· 出牌也蒙眼**：光堵「看牌」不够——阁下敲 `play QK`，命令文本本身就告诉本天使出了哪两张。改**编号出牌**：牌桌图给阁下的牌标 `[1]`–`[5]`，`play 1 3` 按位置出，命令里只有数字。`render` 的「本局已摊」原来把阁下出过的牌印成明文，一并改成只报张数。牌面写法保留（兼容），但 CLI 提醒会暴露。
- **丙 · AI 随机**：`ai_deck_play` 张数与真假配比随机（掺假 8%/16%/24% 按档位；硬约束——出空那一手不能带假）；`ai_deck_challenge` 阈值 ±0.05 抖动。阁下反推不出本天使手牌结构。
- **踩坑**：审计 Tee 若在 `finally` 里先 `close()` 再摘 stdout，解释器退出 flush 会写已关闭文件、把退出码弄脏（自测 5 项假 FAIL）——必须**先恢复 stdout/stderr，再 close**。另外 `sys.exit(消息)` 的文本是解释器在 `finally` 之后才打印的（那会儿 Tee 已摘、进不了日志）——要在 `except SystemExit` 里自己先写一遍、再以整数码退出，否则日志缺口 + 终端重复打印。
- **补丁（同日）· 顺手化**（阁下：「刚刚的一系列行动能用一条 CLI 解决」）：① 一次运行同时打「发群块 + 自用行」（原来看暗牌得补跑 `show --player`，纯属白敲）；② `close` 一条命令办完存档（json + 审计日志）+ md（逐局经过由 `chain` 生成）+ INDEX 重建（存档带 `<!-- meta -->`，INDEX 从它重建）+ 台账一笔 + git 提示；同日多桌靠 slug 尾号防盖、`archived_as` 落戳防重收重复记账。顺带把这条升成 SKILL 铁律 11。

  - 顺手化那一批把自测也翻出个**随机红**：`ph not in logtxt` 拿「开局阁下手牌」当哨兵，而本天使自用行会打印本天使自己的牌，**两副手牌同花（点数组合相同）约 3%**，累积日志一撞就红。改成受控局面 + 独立一桌 + 正对照（见 SKILL 铁律 7 哨兵条）。
