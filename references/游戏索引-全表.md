## 游戏索引

入口 `bin/game`（子命令 = 游戏名，参数原样透传给引擎；引擎也仍可单跑）；引擎在 `scripts/`，规则约定在 `games/<游戏名>/`，状态落 `<数据根>/temp/<游戏名>.*`、归档落 `<数据根>/workspace/records/`。

**外部玩法名先翻译成引擎名，别按字面开局**——同一套外部玩法可能对应本项目多个引擎：骗子酒馆（Liar's Bar）＝ **大话骰**（骰子局：叫「几个几」、开盅掉骰）+ **骗子牌**（牌局：扣牌出牌、质疑换枪）两套。用户报的是外部名（或只说「开一局」）时，**先问哪一套**，并把对应引擎的维护状态一并摊出来（见下方「维护状态」）；别默认挑一个就开局。

| 游戏 | 类型 | 规则约定 | 引擎 |
|------|------|----------|------|
| **扫雷** minesweeper | 裁判向 | `games/minesweeper/rules.md` | `scripts/minesweeper.py` — new / open / flag / show / hint + 公平自证 check / commit / reveal + **close（收桌一条龙：存档 + 承诺 + INDEX 重建 + 台账 + git 提示；终局才收、重收自带挡）** + `--png` 出图。全流程实测过 new→open→flag→hint→check→commit→reveal→CLEAR/BOOM→close |
| **五子棋** gomoku | 对擂向 | `games/gomoku/rules.md` | `scripts/gomoku.py` — new（默认 11×11）/ play / show / undo / resign / **draw（和棋收摊；收之前先穷举剩余空格证明两边都连不成五——别凭嘴说「平了」——再把结果和提交一块报出去）** / level / moves / demo（自对弈出图，不碰对局）/ **close（收桌一条龙：存档 + INDEX 重建 + 复盘照抄 `gomoku_audit.py` + 台账 + git 提示；终局才收、同日撞名加尾号）**；**图每手默认跟着出**（`--no-png` 关）。引擎档位 1–4 写在状态文件里，用户可查可改（4 = 搜杀，会算 VCF / 四三） |
| **大话骰** liars-dice · ⛔维护中 | 对擂向 | `games/liars-dice/rules.md`（教程大纲 `games/liars-dice/tutorial.md`） | `scripts/liars-dice.py` — new（`--variant` 开变体）/ show（`--player` 不泄裁判端骰面）/ bid（用户叫完引擎当场应手）/ open / pi / fanpi / check（承诺哈希复算）/ reveal（局中只摊裁判端那半）/ **close（收桌一条龙：存档 + INDEX 重建 + 逐局经过从 `history` 现生成 + 台账 + git 提示；终局才收、重收自带挡）**；**默认出图**（`--no-png` 关；**用户视角**：他的骰明、裁判端的扣着）。**一手一条命令**：每次运行同时打「发群块 + 自用行」。**蒙眼**（文字层双方只报颗数、**骰面只走棋谱图**——命令本身不带骰面，故无需编号出牌）+ `<state>.audit.log` 审计；游戏级 + 每局级都做盐值承诺；AI 只吃自己的手牌 + 公开叫骰史。变体（反劈/起叫下限/围骰全骰，已落地）、AI 印象层、骗子牌新游戏三件升级计划与进度，见 `references/liars-dice-variants.md` |
| **骗子牌** liars-deck · ⛔维护中 | 对擂向 | `games/liars-deck/rules.md` | `scripts/liars-deck.py` — new / show / play（用户敲图上编号 `play 1 3`，命令文本不带牌面）/ open / check（两条承诺复算）/ reveal / **close（收桌一条龙：存档 + md + INDEX 重建 + 台账 + git 提示；重收、同日撞名自带挡）**；**默认出图**（`--no-png` 关；**用户视角**：他的牌明、裁判端的扣着）。**一手一条命令**：每次运行同时打「发群块 + 自用行」，不必补跑 `show --player`。20 张（6Q/6K/6A+2 王）、每人 5 张、目标牌每局随机；出空 = 对方**必须**质疑（无「认了」）；游戏级（子弹）+ 每局级（手牌）双承诺；**蒙眼**（文字层不给任何一方暗牌明文，牌面只走图）+ `<state>.audit.log` 审计；AI 只吃自己手牌、出牌/质疑带随机 |

| **掷骰决斗** dice-duel | 对擂向 | `games/dice-duel/rules.md` | `scripts/dice-duel.py` — new / roll / show / check / reveal / **close（收桌一条龙：存档 + INDEX 重建 + 台账 + git 提示；终局才收、重收自带挡）**。**没有暗牌，但骰子是裁判端掷的**——公平走盐值承诺：开局封 `salt + seed`（只公布 hash），骰面由种子确定性推出，终局 `reveal` 摊开、`check` 打「独立复算 → 一致 ✓」。**局中摊牌＝这局作废** |

### ⛔ 维护状态（2026-09-15 令）

**大话骰、骗子牌暂停开放——修好之前谁都不许碰。**

- 两个引擎入口都装了维护闸（`maintenance_gate`）：`new` / `bid` / `open` / `pi` / `fanpi` / `play` / `reveal` 一律挡下，只放行只读（`show` / `check`）与收尾（`close`）。
- **解除**：把引擎里的 `MAINTENANCE["on"]` 改成 `False`，**改完就是解封**（引擎只有 `scripts/` 这一份，没有部署副本要同步）。
- 维护作业（自测 / 修完验收）走环境变量 `LIARS_MAINT_OVERRIDE=1` 旁路；自测已默认带上，只有测闸本身时才用 `run(..., bypass=False)`。
- 已修 / 待修清单见 `references/maintenance.md`。

**自测**（临时盘跑，不碰 `temp/`）：`scripts/<游戏名>_selftest.py`（扫雷 / 五子棋 / 大话骰 / 骗子牌 / 掷骰 / 台账各一份）；**动过 AI 再跑** `scripts/gomoku_bench.py verify|ladder|speed`（VCF 穷举复核 / 档位天梯 / 每手耗时）——改过哪个引擎跑哪份，引擎现场跑的就是 `scripts/` 那份。

**复盘 / 采样**（只读落盘棋谱，不改状态）：`scripts/gomoku_audit.py <state.json>` 复盘一局（重放 → 错失 → 威胁 → 死盘断言）；`--sample` 量各盘型的和棋率——盘型选择的依据从这儿来，别拍脑袋。

**战绩台账**（跨游戏，`scripts/ledger.py`）：记一局 `add <游戏> <win|loss|draw> [--moves N] [--level K] [--note 文本] [--source 存档路径]`，看账 `show`。账本 `workspace/records/game-ledger/ledger.json`（文字、进 git）。**收盘必记**——对擂 / 裁判局收摊后（复盘、存档都完了）记一条，别只在聊天里报个比分就算完。自测 `scripts/ledger_selftest.py`。
