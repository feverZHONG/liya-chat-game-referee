# 铁律 8 展开 · 改交付形态先问「怎么整」

> 本文件是 SKILL.md 铁律 8 的展开，规则主文在 SKILL.md。

> 规矩本身（给玩家**多**一样东西随时做；换掉 / 砍掉 / 改默认先问阁下定方向）在 SKILL.md 铁律 8；这份是下面的长子条。

   - **已经批过的口径，铺到兄弟模块不算新 T1**——「蒙眼」这类改动批给了骗子牌，就是整套授权，照它铺到别的暗牌游戏不必再问一遍（要问的只有「这次要改哪几步」）。
   - **阁下把决定权递回来时（「取决于你 / 看门槛高不高」「扔掉都没关系」），别把问题原样推回去**：把成本算清楚（动几处、有没有现成先例、要不要动默认值），直接判、直接做，做完说清理由——以及真要撤掉的话怎么撤。
   - **自测自己也会 stale**：断言别拿开局那份内存快照算——一次 flood 会顺手开掉后面好几格，接着往下跑的那几手全成空转，真正开完盘的收尾那手反而没被检验（「CLEAR 全清」曾因此恒定 FAIL）。每手重读落盘状态，收尾再硬对一次「未开格 == 雷数」。
   - **自测自己也会 stale ②：跨引擎照抄命令前先核那个引擎的开关集**。同族的几个引擎 flag 与默认值会漂（出图有的是默认、有的是 opt-in；`--no-png` 不是每家都有）。argv 被 argparse 挡下时，症状是断言里「那个子串找不到」而不是「参数错」——先看退出码与 stderr 原文，别一上来往渲染层猜。
