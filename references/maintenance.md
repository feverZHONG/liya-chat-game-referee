## 二、已修

### 1. 结算图把裁判端整手暗牌摊成明面（🔴 信息泄露，2026-09-15）

- **现象**：用户质疑后的结算图，把裁判端**下一局**的手牌 / 骰面全部画成明面。骗子牌实战漏了一手（图里 5 张全明，牌与状态对得上），由对局中发现。
- **根因**（三件事叠一块）：
  1. 结算函数内部已经推进到新一局——骗子牌 `pump` 重发牌、大话骰 `resolve` 里 `deal(d)` 重摇；
  2. 紧接着 `emit(..., reveal=True)`，而 `render_png` 的 `reveal` 语义是「翻开裁判端**整手**」，不是「只翻被质疑的那一手」；
  3. 另一侧路径（裁判端质疑用户）用的是 `reveal=bool(d.get("over"))`——**两边不对称**，所以只在用户质疑时漏。
- **修复**：三处 `reveal=True` → `reveal=bool(d.get("over"))`（骗子牌 `cmd_open`；大话骰 `_settle` 两处）。
  开盅 / 翻牌的牌面本来就在文字层 `reveal_text` 里（`裁判端出的 N 张：…` / `裁判端：⚀1 ⚀1 …`），图上不翻**不损失任何公开信息**。
- **取证**（同一局面逐像素对照）：
  - 骗子牌：修前裁判端那排是 A/K/Q 正面填充色（238,224,214 / 226,214,196 / 240,228,200），修后全部 `(196,184,166)` 背面灰；用户那排两张图完全一致。
  - 大话骰：修前黑点像素 2532、修后 0；用户那排 2376（照旧明着）。
- **防回归**：两份自测各加一条断言 + 一条正对照——骗子牌 `backs()` 判「背面灰张数」、大话骰 `dark_pips()` 判「骰子黑点像素」。
  **判据已用真实泄漏图证伪过**（泄漏图 → 0 张扣着 / 2532 黑点像素，断言会 FAIL）。
