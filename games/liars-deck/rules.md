## 一、玩法

- 牌组 **20 张**：6 张 Q、6 张 K、6 张 A、2 张王（J，万能当任意目标牌）。
- 每局双方各发 **5 张**；系统随机定一张**目标牌**（Q / K / A）。王算真 → 每局 **8 张真、12 张假**。
- 轮流**暗出 1–3 张**，宣称「全是目标牌」——可真可假（张数不用跟上家）。
  - **出牌敲图上编号**：牌桌图给阁下的牌标了 `[1]`–`[5]`，`play 1 3` = 出第 1、3 张。本天使只看见数字、看不见是哪两张——**出牌这条路也不漏牌**。
  - 牌面写法（`play QQJ`）仍认，但那句命令会暴露阁下出的是什么；CLI 会提醒一次。
- 出牌后，对方二选一：
  - **质疑**（`open`）：翻牌——**有一张假就算说谎** → 出牌者吃枪；全是真牌 → 质疑者吃枪。
  - **接牌**（`play`）：自己接着出。
- **一方手牌出空** → 该方本轮跳过回合；1v1 下只剩对方有牌 → **对方必须质疑**最后一手（`open`），谁吃枪看那一手真假。
  - 所以**出空的最后一手必须是真的**，否则自己吃枪（官方原话：`must call LIAR`）。
  - ⚠️ **没有「认了 / 弃权」**——官方回合只有「出牌 / 叫 LIAR」两个动作。旧的 `pass` 已于 2026-09-15 废除。
- 吃枪 = 对着自己扣扳机：6 仓 1 弹、**弹位固定**，每扣一次指针走一格，**转到弹仓那一格就出局**（1/6 → 1/5 → 1/4 → 1/3 → 1/2 → 第六枪必死；左轮全程**不重置**）。
- 🔸 **你的牌面只在牌桌图里**：文字层对双方手牌都蒙眼（只报张数）——阁下视角那张图画你的牌明、本天使的扣着。每手**默认就出图**（`--no-png` 关）。
- 一方出局 → 对方赢下这一桌。否则重发牌进下一局，**上一局吃枪的一方先出**。

## 二、CLI 速查

| 命令 | 干什么 |
|------|--------|
| `new [--level 1\|2\|3] [--force]` | 开桌；公布游戏级承诺（子弹）+ 本局承诺（手牌） |
| `show [--player]` | 看盘（**默认就出牌桌图**） |
| `play <编号...>` | 阁下出牌：图上编号 1–5，出 1–3 个（`play 1 3`）；牌面写法仍认但不推荐；引擎当场应手 |
| `open` | 阁下质疑本天使的上一次出牌 |
| `check` | 复算两条承诺哈希（公平自证） |
| `reveal` | 摊牌：终局摊全桌；**局中只摊本天使那半**（局中摊＝这局作废） |
| `close [--note 文本]` | **收桌一条龙**：存档（json + 审计日志）+ md + INDEX 重建 + 台账一笔，末了打出 git 命令。**终局才收**（没收桌会被挡；同一桌重收也会被挡） |
| `--png [路径]` / `--no-png` | 指定图路径 / 这一手不要图；默认写 `<state同名>.png`，每手覆盖同一张 |

出牌容错：`play 1 3` / `play 13` 都行；牌面 `play QQJ` / `play Q Q J` / `play 王 J` 也认（大小写都认）。

**顺手条款 —— 一手一条命令**：每次运行的输出分两段，`── 发群（以下整块照贴）` 到 `── 发群到此` 之间整块照贴阁下；
末尾那行 `本天使手牌（暗牌，别贴进群）` 自用。**不必再补跑一次 `show --player` 去挑可贴的半边**。
收桌同理：一条 `close` 把存档 / INDEX / 台账全办完，别再手工 cp + 手写 md。

## 三、落盘路径

| 文件 | 内容 |
|------|------|
| `temp/liars-deck.json` | 双方手牌（含暗牌）+ 目标牌 + 两把左轮（弹仓位置 + 指针）+ 两份承诺 + 局数 |
| `temp/liars-deck.png` | 每手覆盖的牌桌（阁下视角） |
| `temp/liars-deck.audit.log` | 每次运行本天使可见的输出（审计凭证；含本天使手牌明文——审计请等收桌） |
| `workspace/records/liars-deck/` | **收桌后的存档**：`<日期>-1v1-<结果>-阁下vs莉娅.{md,json,-audit.log}` + 由 `close` 自动重建的 INDEX.md |

## 四、公平（本天使既坐庄又下桌）

1. **两条承诺开局就公布**：游戏级 `sha256(盐 | 本天使子弹 | 阁下子弹)`、每局级 `sha256(盐 | 双方手牌)`；被问就 `check` 复算。
2. **AI 只看自己的手牌** —— 阁下的手牌不进 `ai_p_true` / `ai_deck_play`（公开出牌史也没进）。
3. **蒙眼条款**（2026-09-15 阁下批「甲」）：文字盘面**不打印阁下手牌明文**，牌面只走牌桌图；**出牌敲图上编号**（命令文本里也不带牌面）；本天使三不做——**不 vision 读牌桌图、不 read 状态 json、不翻含暗牌的输出**（局中 `reveal` 也只摊本天使那半；渲染验收走样本盘，不看真实对局图）。
4. **可审计**：每次运行把本天使可见的输出追加进 `<state同名>.audit.log`，阁下可查本天使看到了什么；本天使不动这份日志。⚠️ **日志含本天使自己手牌的明文**——对局中途翻日志＝看本天使的牌，审计请等收桌。**阁下的暗牌对局中只有张数**，摊开后才入日志。
5. **AI 带随机**（同批「丙」）：出牌张数、真假配比、质疑门槛都带随机 —— 阁下反推不出本天使手牌结构。
6. `show`（默认视角）含**本天使**手牌明文 —— 那是本天使自己看的，别原样贴给阁下；要给阁下看就发那张图。

## 五、口吻与收尾

- 对擂向：出牌、质疑都要有对手戏；不复述规则、不报「局势分析」、不当引擎传声筒。
- 翻牌时**照抄 `reveal_text` 的账**（谁出了什么、有假没假、谁吃枪、指针到哪），别自己算。
- 收摊后照 skill 铁律：复盘 + 存档 + 往 `ledger.py` 记一条。

## 六、跟大话骰的分工

- **大话骰**：比「数量」——一口价往上叫，靠概率 + 嘴。
- **骗子牌**：比「真假」——出的是手里的实物，靠诈牌 + 抓诈。
- 两个都是暗牌 + 承诺哈希自证，AI 都只吃自己手牌。
