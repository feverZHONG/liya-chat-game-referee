# 掷骰决斗 · 具体约定

> 家族第五个引擎（扫雷 / 五子棋 / 大话骰 / 骗子牌之后），收编来的——玩法一字未改，
> 交付形态按本库口径重写。引擎：`scripts/dice-duel.py`，自测：`scripts/dice-duel_selftest.py`。

## 规则（本库口径）

- 双方各掷**两枚六面骰**（2d6），点数和大的赢这一掷。
- 两边的和**相同 = 平局**：双方都不计分，直接用同一副骰子掷下一掷（平局不设上限，一直掷到分出胜负）。
- **先赢 3 掷者胜**（记分掷最多 5 掷；平局另算）。
- 骰子**由引擎掷**——双方都看得见，没有暗牌。本玩法不带信息不对称，公平靠**承诺 + 复算**自证，不靠藏牌。
  - 玩家侧只有一条指令：`roll`。没有「你自己报点数」「比大小猜」这类分支——别自己发明玩法。
- **没有难度**：收编时删掉了老脚本的 `difficulty`——它从来不进任何判定，是个空壳选项。

## 命令表

| 命令 | 干什么 |
|------|--------|
| `new` | 开局：封存盐+种子，打印可公布的 hash（**不带参数**，带参数会被挡） |
| `roll` | 掷一手：报这一掷双方点数、结果、比分与距离 |
| `show` | 当前局面：比分 + 逐掷经过 |
| `check` | 自洽校验 + 独立复算 hash 与全部骰谱（公平自证，别手算） |
| `reveal` | 摊开盐 + 种子 + 独立复算（终局摊；**局中摊＝这局作废**） |
| `close` | 收桌一条龙：存档 + INDEX 重建 + 台账 + git 提示（**终局才收、重收被挡**） |
| `help` | 打印用法 |

覆盖开关：`--state <路径>` / `--archive <目录>` / `--ledger <账本>` / `--note <文本>` / `--no-ledger`。

## 落盘路径

| 文件 | 内容 |
|------|------|
| `temp/dice-duel.json` | 状态：`player_score` / `liya_score` / `rolls`（总掷数，含平局）/ `history`（逐掷双方点数与结果）/ `over` / `winner` / `void` / `closed_as` |
| `temp/dice-duel.commit.json` | 公平承诺：`algo`（`sha256(盐|种子)`）/ `salt`（保密）/ `seed`（保密）/ `hash`（可公布） |
| `workspace/records/dice-duel/` | **收桌后的存档**：`<日期>-先3胜-<结果>-阁下.{md,json,.commit.json}` + 由 `close` 自动重建的 INDEX.md |
| `workspace/records/game-ledger/ledger.json` | 跨游戏台账（close 记一笔） |

`history` 的每一项 = `{"n": 掷序, "player": [d1,d2], "liya": [d1,d2], "result": "player"|"liya"|"tie"}`——
close 的「逐掷经过」就是照它现生成的，别手写。

## 公平口径（承诺怎么复算）

1. **开局封存**：`new` 生成 `salt = secrets.token_hex(16)`、`seed = secrets.token_hex(16)`，
   算 `hash = sha256(salt + "|" + seed)`，把 `{algo, salt, seed, hash}` 写进 `dice-duel.commit.json`，
   只打印「承诺已封存，可公布: &lt;hash&gt;」。**盐与种子不公开。**
2. **骰面由种子确定性推出**：

   ```
   第 n 掷、某一方的第 i 枚骰 = sha256("<种子>|n|<player|liya>|i") 取首字节 % 6 + 1   （i ∈ {0,1}）
   ```

   一行复算（阁下自己算）：

   ```bash
   python3 -c "import hashlib,json;cm=json.load(open('temp/dice-duel.commit.json'));f=lambda n,s,i:hashlib.sha256(f\"{cm['seed']}|{n}|{s}|{i}\".encode()).digest()[0]%6+1;print([ (f(n,'player',0),f(n,'player',1)) for n in range(1,6)])"
   ```

3. **承诺是发骰的前提**：`roll` 每次运行都要读 commit 文件，缺了就不发骰
   （`new` 一定先封存）——所以「先公布 hash、后掷」不是嘴上说的。
4. **`check`**：自洽校验（骰面 ∈1..6 / 分数与骰谱对账 / 逐掷按种子重算 / 哈希重算），
   末行打「**独立复算 → 一致 ✓**」。被问「童叟无欺？」时照抄 `check` 的输出 + 可公布的 hash。
5. **`reveal`**：摊开盐 + 种子 + 自己独立复算一遍哈希（对不上会打 ✗）。终局摊牌后阁下可把
   每一掷自己重算一遍。**局中摊牌＝这局作废**：状态落 `void`，此后的 `roll` / `close` 一律被挡，
   要接着玩必须先 `new`（作废的盘不收桌、不入档——种子公开了，后面每一掷谁都能提前算出来）。

## 胜负口径与台账

- 胜负按盘算（**本天使视角**记台账，与家族一致）：
  - **本天使先赢 3 掷 → 台账 `win`**；**阁下先赢 3 掷 → 台账 `loss`**。
- `close` 记的 `--note` 默认写：`引擎执骰：先3胜 · 阁下 3 : 2 本天使（7 掷，含平局 2）`。
- 比分报「阁下 a : b 本天使」，逐掷报「阁下 / 本天使 各自两枚点数」，别把两边写反。

## 收桌（一条命令）

终局（某一方先赢 3 掷）之后：

```
python3 dice-duel.py close                    # 存档 + INDEX 重建 + 台账一笔 + git 提示
python3 dice-duel.py close --no-ledger        # 只存档
```

- 把 `temp/` 的那份状态 + 承诺拷成一档，md 的「逐掷经过 / 自洽校验 / 承诺复算」全是脚本输出
  （`check` / `reveal` 的同一份文本，别手写），INDEX 按各档 md 的 `<!-- meta -->` 重建。
- 防呆：没终局不收；同一盘重收被挡（状态里落 `closed_as` 戳）；同一天连开两盘 slug 自动加尾号；
  作废盘（`void`）不收。
- **承诺与 close 已落地**（不是计划）：开局即封存、每掷从种子推、终局摊牌、收桌入档一条命令都在。

## 渲染

- 骰面用 `⚀⚁⚂⚃⚄⚅`（U+2680–2685），一手一块，照着 CLI 输出贴，别手打。
- 每手四行就够：第几掷 → 本天使点数 → 阁下的点数 → 结果 + 比分与距离。
- **引擎只吐事实**（点数 / 比分 / 局面 / 还差几掷），**不吐台词**：老脚本那套 `COMMENTS`
  预设台词池收编时已删——聊天里引擎就是本天使，台词本天使现编。别写小作文、别每手复述规则。

## 坑

- **别手塞种子**：每次 `roll` 都从 commit 文件读种子，文件丢了引擎直接停手（这是有意的：
  承诺是公平的前提）。要接着玩就 `new`——别临时造一个种子继续，那等于把公平拆了。
- **别手改 json**：`history` 与比分对不上，`check` 会当场打「对不上 ✗」；一律走 CLI。
- **`new` 会清掉上一盘的 commit 文件**（旧盘残留会让新盘的种子不算「先封后掷」）。
- **上一盘没打完就 `new`**：引擎会给一句提醒（状态会被覆盖，比分也打在里面）——
  本天使要把这句话说出来，别闷头重开。
- **局中 `reveal` = 作废**，作废盘不收桌不入档；要留档必须另开一盘重打。
- **平局概率是 146/1296 ≈ 11.3%**（两个 2d6 的和相等），不是 1/6——报概率别报错。
- **别把种子写进 skill / md / memory**：对局进行中种子只许活在这盘的 `.commit.json` 与
  `temp/` 状态对应的活盘里（`check` 的常规输出不含盐与种子，可以照抄）。
- **会话过期**：QQ 掉线后照样能接——`find "$GAME_HOME/temp" -maxdepth 2 -name 'dice-duel*.json'`
  把盘捞回来接着 `roll`，别重开一局冒充原来的比分。
- **路径解析不写死**：数据根 `$GAME_HOME` ＞ 往上找带 `temp/` 或 `workspace/` 的一层 ＞ 脚本上一级；
  引擎靠同级找 `ledger.py`，**拷副本时必须连兄弟脚本一起拷**（自测的临时副本就是这么干的）。
