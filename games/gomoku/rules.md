# 五子棋对擂 · 具体约定

> 跟扫雷不是一类：扫雷是**裁判**（藏答案、看阁下一个人玩），五子棋是**对擂**（本天使下场当对手）。
> 全信息，没有隐藏答案——所以「公平自证」那套盐值承诺在这儿用不上，公平改由**档位公开**来保证。
>
> **关键在口气，不在谁算哪一手。** 对擂不是「换成第一人称播报对局」——是本天使真要赢这一盘：接招、封路、反扑，有胜负欲，有对手戏。总则见 SKILL.md「输出节奏 · 对擂向」。

## 规则（本库口径）

- 默认 **11×11**，**连五即胜**；长连（六子以上）也算赢，**不做禁手**（休闲局，别拿连珠那套规矩为难人）。
- 阁下默认执黑先手；`new --human white` 换阁下执白，引擎自动占天元。
- 一手一子，落子不悔（`undo` 是「阁下 + 引擎」各退一手，不是本天使帮你改棋）。
- 盘满未成五 = 和棋；两边都看清是死盘时也可以协商提前收摊（`gomoku.py draw` 落盘记和，结果一样）。
  - **别只凭嘴说「平了」**：收摊前把剩余空格穷举一遍（≤15 格直接 2^n 暴力，2048 种秒出），能证明双方都不可能连五才叫死盘——嘴上的「没活了」不算数。这是对擂里唯一的「自证」环节。
- 盘型 `--size 5–26`；**列数上限 26**（坐标只有 A–Z 单字母）。QQ 上 9–11 最舒服——9 是一行 21 字符、一屏看全，11 是 25 字符、战术空间大些（13 以上就得横向滚了）。
  - **盘越小越容易收和**（档 2 自对弈采样，每盘型 12 局随机开局）：9×9 和 10/12（盘满率 89%）、11×11 和 7/12（73%）、13×13 和 4/12（53%）、15×15 和 1/12（25%）。9×9 想收官有胜负基本靠对面犯错——只适合「快速局」，别拿它验棋力。

## 坐标 ↔ 索引

- `X#` → `(row=#-1, col=ord(X)-65)`，**0 基**，如 `E5` = 第 5 行第 5 列（11×11 的天元是 `F6`）。
- 半角大写、行号两位不限（`A10`、`A11` 合法）。列头按盘型给（11×11 是 `A–K`），行号右对齐。

## 符号

| 样式 | 空 | 黑 | 白 | 说明 |
|------|----|----|----|------|
| `classic`（默认） | `.` | `X` | `O` | 全半宽，绝对对齐，任何客户端都不歪 |
| `cjk` | `＋` | `●` | `○` | 全宽，好看；歪了就换回 classic |

- 最后手不画在盘上，由统计行点名（`最后手 E5（黑）`）。
- **图每手默认跟着出**（`temp/gomoku.png`，每手覆盖同一张；`--no-png` 关）：图里最后一手点一个红心，阁下不用从字符堆里推盘面。
- **文字仍是主体**：可复制、图挂了也照样玩——回话里 `MEDIA:` 附在文字盘面**之后**，不许只发图。

## 引擎档位（公平靠这个）

档位写在状态文件里，**阁下随时可查**（`level`），也可以随时改（`level 1|2|3|4`，下一手生效）。

| 档 | 名 | 性格 |
|----|----|------|
| 1 | 陪练 | 只看眼前、漏堵活三；成五 / 堵五还是会做的 |
| 2 | 对等 | 会堵活三、会做四，评分权重拉满（默认） |
| 3 | 较真 | 在档 2 之上会避杀：不把活四 / 四三送到对面手里（自己还不做杀） |
| 4 | 搜杀 | 算得出「连着的杀」：连续冲四（VCF）、四三定式、活四/双四；自己算不出杀时回头拆对面的杀 |

- **档 4 的搜杀范围**：只认**连续冲四**和「四 + 活三」这类定式，加一层「别把杀招送给对面」的校验（对手 VCF / 活四 / 四三）。跳三跳四这种断点棋型它同样认不全——**留给人赢的口子还在**。每手 ~0.1s（档 2 是毫秒级），聊天里不卡。**要较真直接上档 4。**

- **引擎只认形状，不认官子**：评分函数数的是「连续子数 + 两端开放」，识别不了跳三、跳四这类断点棋型——这不是 bug，是留给人赢的口子。双三 / 双四就是阁下的赢法。
- 被问「你是不是放水」时：档位拿出来给他看，别辩解。要真较真就 `level 4` 当场加档。
- **档位封顶在 4，不再往上加**：五子棋的正解是威胁空间搜索 + 证明数搜索（Allis 1994 / Victoria——「先手必胜」就是这么证的），跟深度学习、给 minimax 加层都不是一条路。这条路探过一遍，结论已定：**四档定版，输赢算阁下自己的**。再提「加个 minimax / 上模型」= 没记住。

## 演示 / 验收

`python3 scripts/gomoku.py demo [手数] [--vs-level N] [--out 路径]` —— 自对弈一段并出图，**不碰正式状态、不占对局图**（默认写 `gomoku-demo.png`，脚本同目录）。

三处用得上：给阁下看效果；改过渲染代码后出图瞄一眼（比开一盘快）；想看看引擎在某个档位下会下成什么样。默认 20 手、两边同档。

`python3 scripts/gomoku_bench.py verify|ladder|speed [盘型]` —— 引擎体检台：VCF 杀招**穷举应手复核**、档位天梯（随机开局对擂）、每手耗时。跟自测分工：`gomoku_selftest.py` 管「会不会崩、记不记得规矩」，bench 管「棋力有没有退」——**动过 AI 就两边都跑**（2026-09-14 就是靠 verify 抓出「双四杀里没算对手现成的五」这个 bug）。

收盘复盘 / 量盘型和棋率：`python3 scripts/gomoku_audit.py <state.json>`｜`--sample`（只读，不碰状态）。

## 收桌（一条命令）

终局（五连 / 和棋 / 认输）之后：`python3 scripts/gomoku.py close` —— 存档（json + md）+ INDEX 重建 + 复盘（照抄 `gomoku_audit.py`）+ 台账一笔 + git 提示，一次办完。`--no-ledger` 只存档。
防呆：没终局不收、同一盘重收被挡、同一天连开两盘 slug 自动加尾号。

## 落盘路径

| 文件 | 内容 |
|------|------|
| `temp/gomoku.json` | `size` / `level` / `human` / `board`（0 空 1 黑 2 白）/ `moves`（棋谱，公开）/ `winner` |
| `temp/gomoku.png` | 每手覆盖的盘面图（默认出，`--no-png` 关） |

- **`moves` 就是棋谱**：每一手有时间顺序，阁下能从头复看。本天使要解释任何一手，都从这儿说。
- 没有 commit 文件——五子棋不藏东西。
- **旧棋谱存档**：终局后一条 `close` 收桌——拷一份到 `workspace/records/gomoku/`（`<日期>-<盘型>-<结果>-<对手>.md` + 同名原始 `.json`，INDEX 由它重建；md 里的终局盘面 / 棋谱 / 复盘全是脚本输出，包括照抄 `gomoku_audit.py` 的复盘）。**`temp/gomoku.json` 只活在当前这盘，开新盘就被覆盖——要留必须先收桌。**
  - 防呆：没终局不收；同一盘重收被挡；同一天连开两盘 slug 自动加尾号。
  - `close` 会把「认输」这类非五连终局标清楚（`终局：白胜（对手认输）`），别让存档把认输写成五连。

## 坑

- **别拿引擎心算**：每一手都走 `play`，别本天使自己推一个「我觉得该下这」然后手改 json。手改必错位，而且阁下查不出你下过什么。
- **不资敌**：不许说「你该堵 G7」「你这里能凑个双三」这种话——对擂时这不是「不给答案」，是**把刀递给对手**。本天使在争这盘，没道理告诉阁下哪儿能赢。说**自己的意图**（「这儿封死了」「本天使要在这儿做文章」）是对手戏；指点阁下的机会是资敌。
- **不做解说**：别报「目前盘面……」「引擎评分……」这种中立腔，也别当引擎的传声筒——引擎算落点，人格给口气。
- **档位不是放水的借口**：不许说「本天使这手可能下得不好」之类的场面话——那是裁判在解说自己的对局。要么下，要么不说。档降了就是真弱，不是嘴上让。
- **胜负说胜负的话**：赢了就拿下来（不羞辱，也不「承让」）；输了认账、不服、约下一盘。**不颁奖**——「恭喜阁下获胜」一出口，裁判腔就漏了。
- **档位别偷偷改**：改档要经 `level` 命令落盘，阁下查得到。中途手改 = 作弊。
- **改过脚本先自测**：`python3 scripts/gomoku_selftest.py`（36 项：全流程 + AI 三场景 + 档 4 五道定式题 + 四档自对弈，临时盘不碰 temp/）。扫雷那份 `selftest.py` 是别的游戏专用，跑不了这个。**动过 AI 再加跑** `scripts/gomoku_bench.py verify`（VCF 穷举复核）和 `ladder`（档位对比）——自测只管「崩不崩」，棋力退没退只有 bench 看得出来。
- **AI 太强比太弱更难救**：档 2 默认已经会堵活三、会做四；要是实战发现阁下被压得没脾气，先降档，别急着改评分函数——改权重是给两边都换手感，降档只动一边。
- **渲染对齐**：`classic` 全半宽稳；`cjk` 好看但依赖字体全宽，歪了就换回去。**别混着用**。
- **档位不是严格阶梯**：11×11 上「档 4 执白 vs 档 3 执黑」个别开局（黑首手 E4 这类）档 4 仍会输——先手在空盘上就是便宜。别把这当 bug 追；要验强弱看 `gomoku_bench.py verify` 的定式题，别看几盘胜负。
- **「多算一层」不等于更强**：档 3 原来那套前瞻（我下 → 用对手最狠的一手扣分）实测把自己下软了——档 3 执黑对档 2 只有 **2 胜 19 负 27 和**，比低一档还差。根子在「扣分」让它一味退让、把先手让出去。已换成 `avoid_threat_moves`（只硬查对面有没有**立刻成杀**的手）。**给 AI 加「前瞻」这类改动，必须拿对局数据验，别凭直觉。**
- **算杀要连对面一起算**：`vcf` 判「活四 / 双四 = 赢」时，得同时确认**对面手里没有现成的五**——不然人家先收，你那条连杀是假的（实测抓出来过，反例 6 个）。
- **满盘不是非法手**：9×9 只有 81 格，自对弈/长局真能下满——`candidates` 满盘返回空表、`ai_choose` 返回 `None`，调用方按「没得下」按住；别退回天元那种已占的点（11×11 盘大跑不满，这个 bug 就是换 9×9 才暴露的）。
- **终局后要 `new` 才能续**，`play` 会挡住并提示——别默默吞掉一步。
- **`undo` 退的是整回合**（阁下那手 + 引擎的应手），不是单步回退；终局后也能退，退完 `winner` 清空接着下。
- **别删存档 md 头部的 `<!-- meta {...} -->`**：INDEX 是从它重建的——删了那一档，下次收桌它就整行消失（存档还在，但没人找得到）。
