# 大话骰 liars-dice · 聊天版规矩

> ⛔ **维护中（2026-09-15 阁下令）——修好之前谁都不许碰。**
> 引擎入口装了维护闸：`new` / 叫骰 / `open` / `pi` / `fanpi` 一律被挡，只放行 `show` / `check` / `close`。
> 待修清单与解除办法见 `references/maintenance.md`。

引擎 `scripts/liars-dice.py`，状态 `temp/liars-dice.json`，自测 `scripts/liars-dice_selftest.py`。

## 一、玩法（房源版，跟老仓库一致）

- 每人 5 颗骰，扣盅摇；输一次掉一颗，掉光出局。
- 叫骰格式「数量个点数」——「3个5」= 全场至少 3 颗 5 点。
- 「1」万能，可当 2–6 任何点；叫「**斋**」则 1 作废。
- 顺子（各点不同）算 **0** 颗；豹子（全同点）额外 **+1** 颗。**双方顺子都自动重摇一次**——老版只给 AI 重摇，聊天版拉平了这把尺子（要改回去说一声）。
- 只能往上叫：加数量，或同数量换更大点。
- 「斋」后只能跟斋，或「**飞**」破斋（数量 ≥ 上一注 ×2）。
- 「**开**」= 质疑，亮骰核对：叫骰成立 → 质疑者掉 1；吹破 → 叫骰者掉 1。
- 「**劈**」= 双倍赌注的质疑，输的一方掉 2 颗。
- 先叫权：开局阁下先叫；之后**每局由上一局被罚的人先叫**（轮到本天使就先叫出来）。

## 二、CLI 速查

| 命令 | 干什么 |
|------|--------|
| `new [--dice 5] [--level 1\|2\|3] [--variant fanpi\|minbid\|quan] [--variants all] [--force] [--png]` | 开桌；当场公布承诺哈希；`--variant` 开变体（见第七节） |
| `show [--player] [--png]` | 看盘；`--player` 是能照抄给阁下的那一版 |
| `bid <数量个点数[斋\|飞]> [--png]` | 阁下叫骰；**引擎当场给出本天使的应手**（叫或开）——一条命令一个回合 |
| `open` / `pi` / `fanpi` | 阁下开盅 / 劈 / 反劈（`fanpi` 需先开了反劈变体，且本天使刚劈过） |
| `check` | 复算承诺哈希（公平自证） |
| `profile [--path P] [--clear]` | 看 / 清跨局「对手画像」（第八节） |
| `reveal` | 摊牌（终局用；**局中只摊本天使那半**，摊全＝作弊＋这盘作废） |
| `close [--note 文本]` | **收桌一条龙**：存档（json + md + INDEX 重建）+ 台账一笔，末了打出 git 命令。**终局才收**（没收桌会被挡；同一盘重收也会被挡；同一天连开两盘 slug 自动加尾号） |

叫骰输入容错：「3个5」「三个5」「3个5斋」「6个5飞」都认。

**图默认每手都出**（`<state同名>.png`，每手覆盖同一张；`--no-png` 关）——**骰面只走这张图**，
回话里把 `MEDIA:<路径>` 附在文字后面；文字仍是主线（可复制、图挂了也读得到颗数与叫骰链）。

**顺手条款 —— 一手一条命令**：每次运行的输出分两段，`── 发群（以下整块照贴）` 到 `── 发群到此` 之间整块照贴阁下；
末尾那行 `本天使的骰盅（暗牌，别贴进群）` 自用——**不必再补跑一次 `show --player` 去挑可贴的半边**。
收桌同理：一条 `close` 把存档 / INDEX / 台账全办完，别再手工 cp + 手写 md。

## 三、落盘路径

| 文件 | 内容 |
|------|------|
| `temp/liars-dice.json` | 双方骰子（含暗牌）+ 当前叫骰 + 叫骰链 + `history`（逐局经过）+ 盐 / 承诺哈希 + 骰数 / 局数 / 难度 |
| `temp/liars-dice.png` | 每手覆盖的棋谱图（**阁下视角**：他的骰明、本天使的扣着）——骰面只在这张图里 |
| `temp/liars-dice.audit.log` | 每次运行本天使可见的输出（审计凭证；⚠️ 含本天使手牌明文——审计请等收桌） |
| `workspace/records/liars-dice/` | **收桌后的存档**：`<日期>-<N骰>-<结果>-阁下vs莉娅.{md,json}` + 由 `close` 自动重建的 INDEX.md；`profile.json`（对手画像）也在这层 |

## 四、公平（本天使既坐庄又下桌，这几条是底线）

1. **承诺哈希开局就公布** —— `sha256(盐 | 本天使的骰 | 阁下的骰)`；局中谁都不能换骰，被问就 `check` 复算给阁下看。
2. **AI 只看自己的手牌 + 公开的叫骰历史** —— 阁下的手牌根本不传进决策函数。被问「你是不是偷看我牌了」就拿这条回。
3. **蒙眼**（2026-09-15 补，与骗子牌同一套）：文字层**对双方手牌一律只报颗数**，骰面只走棋谱图；
   本天使三不做——**不 vision 读棋谱图、不 read 状态 json、不翻含暗牌的输出**（局中 `reveal` 只摊本天使那半）。
   大话骰比骗子牌省一步：**阁下敲的命令本身不带骰面**（叫骰是「3个5」），所以没有「编号出牌」这回事。
4. **可审计**：每次运行把本天使可见的输出追加进 `<state同名>.audit.log`，阁下可查本天使看到了什么；本天使不动这份日志。
   ⚠️ **日志含本天使自己手牌的明文**——对局中途翻＝看本天使的牌，审计请等收桌；**阁下的骰面对局中只有颗数**，开盅（公开摊牌）后才入账。
5. **AI 带随机**：叫骰张数取舍、质疑门槛都带随机 —— 阁下反推不出本天使手牌结构。
6. `show`（默认）那一版含**本天使**骰面明文 —— 那是本天使自己看的，别原样贴给阁下；要给阁下看就发那张图。

## 五、口吻与收尾

- 对擂向：叫骰、开盅都要有对手戏；不复述规则、不报「局势分析」、不当引擎传声筒。
- 开盅时**照抄 `reveal_text` 的账**（谁几点、合计数、谁掉几颗），别自己算。
- 收摊后一条 `close` 收桌（存档 + INDEX + 台账 + git 提示），**别再手工 cp / 手写 md / 手改 INDEX**。

## 七、变体（opt-in）

默认全关 = 上面那套房源版。开局要开：`new --variant fanpi --variant minbid --variant quan`（或 `--variants fanpi,minbid,quan` / `--variants all`）。开了会写进状态文件、`show` 里公开——规则可查，中途不可改。

| 变体 | 内容 |
|------|------|
| `fanpi` **反劈** | 赌注：开 1 码 / 劈 2 码 / 反劈 4 码（按掉骰数）。阁下劈 → 本天使可能反劈（AI 判）；本天使劈 → 阁下用 `fanpi` 反劈或 `open` 认账 |
| `minbid` **起叫下限** | 每局第一手：喊 1 / 叫斋 ≥ 存活人数；非斋 ≥ ⌈总骰数×0.3⌉ |
| `quan` **围骰/全骰** | 围骰（1 + 单一点数）该点 +1、全骰（全同点）+2；被开者（叫骰方）判输时手里是围骰/全骰 → 惩罚翻倍 |

规则依据与外部参考见 `references/liars-dice-variants.md`。

## 八、对手画像（跨局）

本天使这边记着一份**阁下风格画像**，跨局累积、落 `workspace/records/liars-dice/profile.json`。**只从公开信息提炼**——阁下叫过什么、谁质疑、摊牌后算出实际颗数；碰不到阁下的手牌（同第四节铁律）。

- 看 / 清：`profile`（`--path` 换文件、`--clear` 清空）；开局加 `--no-profile` 这盘不记。
- 维度：开盅率、诈叫率、叫骰激进程度——样本够（叫骰 ≥3 手 / 摊牌 ≥3 次）才给，**不硬凑**。
- 用途：混进 AI 的激进估计、压质疑门槛——阁下越爱诈，本天使开得越凶。
